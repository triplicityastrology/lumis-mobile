# Care Circle Preview Boundary

Care Circle is preview-only in the active mobile build. Release navigation may
open the static preview from Profile, but it must not expose linking, codes,
scanning, check-ins, cadence, reminders, notifications, emergency actions,
scheduling, billing, or entitlement behavior.

The preserved prototype source is not release authority and must remain
unreachable until a separately approved implementation batch supplies the
backend, privacy, safety, and device evidence.

The following Carer/Caree v0.3 documents remain the future implementation authority
and are not modified by this boundary:

- `01_Functions/01_Carer_Caree_Care_Circle/01_Business_Process/Carer_Caree_Business_Process_and_Technical_Requirements_v0.3.md`
- `01_Functions/01_Carer_Caree_Care_Circle/06_Decisions_and_Approvals/Carer_Caree_Business_Process_and_Technical_Requirements_v0.3.docx`
