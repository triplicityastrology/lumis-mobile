# S2-T89 Persona Behaviour Runtime Boundary

This is inactive, server-only technical infrastructure. It has no mobile caller and performs no model or provider call.

The v1 assembler accepts only an already-calculated persona profile. It applies the controlled order: safety, emotional state, immutable role contract, calculated profile, exact behaviour mapping, conflict resolution, then language. Safety suppresses conflicting persona modifiers. The model is never asked to calculate signs or invent sign stereotypes.

The registry contains the 60 reviewed workbook rows. Prompt payloads carry resolved factor/sign pairs, approved modifiers, versions, fallbacks, and language. They exclude mapping IDs, offset arithmetic, source signs, and raw workbook data from user-facing output.
